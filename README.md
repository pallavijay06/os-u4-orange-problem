# OS Unit 4 Orange Problem

## Project Overview
This project implements a simplified local version control system similar to Git using the C programming language. The system supports repository initialization, object storage, staging through an index, commit history management, branching concepts, checkout handling, and garbage collection.

## Features
- Repository initialization
- Object storage using hashes
- Tree serialization
- Index and staging area
- Commit history tracking
- Branch references and HEAD handling
- Garbage collection and unreachable object removal

## Technologies Used
- C Programming
- Linux File System
- GCC Compiler
